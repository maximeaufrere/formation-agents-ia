# Agents IA et Claude Code

Auto-formation en français, en deux parties (fondamentaux des agents IA, puis Claude Code), chaque chapitre expliqué en trois niveaux de profondeur.

**Lire la formation : https://maximeaufrere.github.io/formation-agents-ia/**

## Lire en local

Aucune installation ni build : ouvrir `index.html` dans un navigateur.

## Publication

Chaque push sur `main` (déploiement Actions, sans Jekyll) publie le site sur GitHub Pages via `.github/workflows/pages.yml`. Seuls les fichiers `*.html` et le dossier `assets/` sont publiés.
